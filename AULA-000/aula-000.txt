2. Linguagem, paradigma e domínio
Defina com suas palavras: linguagem de programação, paradigma e domínio de aplicação. Depois, dê um exemplo que relacione os três conceitos.
R:
- Linguagem de programação: Conjunto de regras sintáticas e semânticas usado para dar instruções ao computador.
- Paradigma: Estilo ou modelo de organização da lógica de um programa.
- Domínio de aplicação: Área de atuação ou tipo de problema a ser resolvido pelo software.
Exemplo: Na área de análise de dados (domínio), usa-se Python (linguagem) aplicante o paradigma funcional para filtrar conjuntos de dados sem alterar o estado original.

9. Escolha de linguagem

R:
1. Prazo: Python permite desenvolver bem mais rápido.
2. Experiência do time: A equipe já conhece Python, o que diminui erros.
3. Ecossistema: Python possui bibliotecas prontas para análise de dados.
4. Desempenho necessário: O requisito é moderado, então linguagens de baixo nível não trarão benefício relevante.
5. Manutenibilidade: O código em Python é mais enxuto e simples de manter.
É melhor manter o uso do Python.

10. Trade-offs
Explique por que não existe uma linguagem objetivamente melhor em todos os aspectos. Apresente dois exemplos de trade-off...
R:
Nenhuma linguagem é perfeita para tudo porque priorizar uma característica sempre exige abrir mão de outra.
Exemplos:
1. Produtividade vs Controle: Linguagens de alto nível aceleram o desenvolvimento, mas tiram o controle fino sobre a memória.
2. Segurança vs Desempenho: Checagens extras de memória evitam erros, mas deixam a execução um pouco mais lenta.

13. Desafio prático
Implemente, em qualquer linguagem, um programa que receba uma lista de números e produza: (1) a soma dos pares; (2) a quantidade de valores positivos; e (3) o maior valor. Depois identifique o paradigma predominante da sua solução e explique como ela poderia ser reescrita em outro estilo.
R:
Código em Python:
def analisar(numeros):
    if not numeros:
        return 0, 0, None
    soma_pares = sum(n for n in numeros if n % 2 == 0)
    qtd_positivos = sum(1 for n in numeros if n > 0)
    maior = max(numeros)
    return soma_pares, qtd_positivos, maior

- Paradigma predominante: Funcional / Declarativo simples (processamento via expressões e funções prontas, sem modificar estado).
- Reescrita em estilo Imperativo: Usar um laço `for` tradicional com variáveis mutáveis acumulando os valores passo a passo (`soma += n`, etc.).
